# Video Shotcraft 完整模板接入

上游：[Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft/tree/5ddbf521038b0a7accfb6dc1e0a9eb29c67277ab)，固定提交 5ddbf521038b0a7accfb6dc1e0a9eb29c67277ab。

已接入 242 个完整材料条目，覆盖上游 157 张镜头卡的 214 个画廊变体，包括所有独立 demo、6 个成片场景、9 套完整成片主题和共享组件。flash-cut 的画廊配方由上游页面相机和原始 FlashCut 组合，单独提供完整示例。原有 12 个核心动效和 9 个项目风格继续可用。本机现有 272 个动效、13 个风格。

交互预览：[本地模板画廊](../assets/motion-library/shotcraft-gallery.html)。每项材料都有 component.jsx、usage.md、demo.mp4 和抽帧证据。完整条目的 id 均以 shotcraft-template- 开头，可按画面意图通过 video:library search 检索。

## 保留与适配

- 保留原始页面结构、卡片/表格/导航布局、镜头运动、转场、图形与通用固定文字。示例人物、数值和图表作为示例内容保留，不能当作正在制作的项目事实。
- 非通用品牌与示例项目名改为中性名称，逐项替换记录在 definitions.json 的 changedCopy 与每项 usage.md。搜索用词和布局标题同步；需要限定字形的描边标题补齐 WORKSPACE 的 W/O/K/C，文字合拢的总宽度随最终单词变化。
- 截图类保留图片依赖。使用原始页面 HTML 和坐标生成 243 张去品牌本地 PNG（27 张裁片 × 9 主题），保留整页和卡片裁片；默认图片嵌入组件哈希覆盖范围，同时保存独立 PNG 供替换。原始布局另存 live-layout。
- Three.js、React Three Fiber 与 Remotion Three 已安装；相机位置由影片帧计算，离线导出与任意帧预览使用同一时间。
- 原始循环视频组件保留截取、循环、裁切与字幕接口，使用 Html5Video 兼容本地演示视频；示例视频和 440Hz 音频由本机 FFmpeg 生成。

## 使用完整模板

从项目生成的 ./motion-library.jsx 导入该条目的 exportName。在 Sequence 中采用 usage.md 给出的 30fps 时长；帧率和时长应与模板一致。固定时长模板在更长叙事中通过镜头编排衔接。

接口：copy 为原文到新文案的字典；config 覆盖原始大写常量（使用完整源码路径#常量名可消除同名歧义）；originalProps 透传原组件的所有输入。theme 只映射原组件已有的 ACCENT，完整成片预设沿用原始视觉主题；主题间几何保持一致。

截图接口 screenshots 的键是原始 textures/live/文件名.png，值是影片 public 中真实截图的相对路径；layout 提供匹配截图的完整页面坐标。如果截图结构变化，必须同步裁片、坐标、文件名和搜索目标。TypeAndFilter 的 config.QUERY、config.NANO_TITLE 与 layout.projects.cards.title 必须一致；SceneFlyIn 可用 copy 的 nano-lab 原文键和匹配 layout 替换搜索目标。截图嵌在 PNG 内的文字须重新截图，不能只传 copy 修改。

例如，选择 shotcraft-template-type-and-filter，用截图相对路径覆盖 textures/live/projects-empty.png 和 card*.png，提供匹配的 layout，再通过 config.QUERY/config.NANO_TITLE 设定真实项目查询词。使用上游特定页面结构时也可直接保留默认中性截图。

## 外部来源未确定的部分

完整成片模板默认静音，音效时点与字幕结构保留。上游部分 Mixkit 音效未提供足够的逐文件来源/授权记录，未复制这些音频；可通过 audio 对象按原文件名提供已经暂存的本地文件。此任务不把静音演示当作正式音画成片批准。

StreamResponse 的 agent-stream.jpg 缺少独立图片来源，已换成本地生成的去品牌截图，图片输入依赖保留。VerticalTicker 的头部另指向 vibe-motion/skills，独立授权链不完整，采用本地兼容实现保留滚动循环、卡片排列和输入接口，未把外部实现纳入可执行材料；原始文件只保留在来源核对档案中。社区展示的外部视频、用户品牌媒体和上游技能/安装器不作为模板材料启用。

## 验证范围

全部模板逐帧输出为 480×270、30fps 的 H.264 MP4，FFmpeg 全片解码；每项检查首帧、25%、50%、75% 和末帧画面，检查截图、字形、排版、终态。3D、视频循环和截图配置还通过实际项目导入桥做预览验证。抽帧检查用于材料接入，不等于目标影片的逐秒人工审片；正式制作继续遵守项目音频优先与视觉批准门禁。
