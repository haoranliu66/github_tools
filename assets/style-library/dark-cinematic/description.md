# 深色产品演示

ID：dark-cinematic

## 风格概述

深蓝黑背景、浅色文字和青色高光，以宽阔主舞台、透视界面与光影层次营造电影感，镜头连续推进到重点。适合科技产品演示、核心功能揭示和性能亮相。

## 配色与层级

背景使用 radial-gradient(ellipse at 70% 15%,#16344e,#0b1020 65%)；正文 #f2f4ff，次级文字 #929ab4，重点 #65dcfb，内容面 #171e32，分隔线 #344567。强调色用于当前关键对象与结论。

## 字体与文字

标题使用 Microsoft YaHei, sans-serif，字重 800；正文使用 Microsoft YaHei, sans-serif，代码与数字说明使用 Consolas, monospace。主标题、标签与字幕保持明确大小层级。

## 构图与空间

画面以一个主角对象建立宽阔舞台，辅助信息分布在前后层；总览与特写保持对象位置和空间关系。

## 材质与图形

深色面板、柔焦光晕、细亮边和柔和投影共同建立纵深；界面截图与几何图形沿用同一光色。 面板圆角 24px，边框 1px；阴影 0 22px 70px #0002。

## 运动与转场

持续运镜与有目的的落点相结合，平移推近后停留阅读；焦点切换保持对象连续，重点出现再给强调拍。

## 字幕

字幕使用 #fff，底条 #10131fe6，字号基准 36px，圆角 14px；底部位置与安全区随画幅重排，关键词沿用重点色。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。 保留同一对象的空间层级与关注点。
