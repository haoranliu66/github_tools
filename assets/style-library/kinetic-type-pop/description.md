# 节拍大字报

ID：kinetic-type-pop

## 风格概述

高对比底色、超大粗体和荧光色关键词，以字重脉冲、字形推近和硬切把文字变成画面主角。适合短知识钩子、观点输出、发布预告和年度数据回顾。

## 配色与层级

近黑底与暖白字形成强对比，荧光黄绿只点亮当前关键词；大块纯色可随语义章节切换。

## 字体与文字

中文采用微软雅黑或黑体回退，标题粗重且短，字号明显大于正文；单词、数字和标点可独立成为图形。

## 构图与空间

以大字报构图为核心，一句主张先占画面，后续词句通过大小、对齐和留白接管焦点；事实图表与文字形成前后主次。

## 材质与图形

用纯色平面、粗线与少量印刷颗粒，字形本身承担视觉冲击；形状用于标记和节奏回应。

## 运动与转场

关键词跟随旁白重音放大或加粗，字形可跳切、错峰升出与形变接力；观点落定后停留，让节奏来自实测语音。

## 字幕

主标题与旁白字幕分层；字幕保持稳定底部位置，强调词可以同步变色，避免同一句在多个层面抢占阅读。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。
