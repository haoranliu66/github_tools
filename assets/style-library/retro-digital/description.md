# 复古数字桌面

ID：retro-digital

## 风格概述

浅灰早期桌面窗口配像素网格、等宽字与电蓝选中块，指针点击、窗口弹出和步进式切换组成低保真数字叙事。适合计算机发展、开发者工具、软件机制和怀旧内容。

## 配色与层级

蓝灰桌面上用浅灰窗口、深色等宽文字与电蓝选中块，状态条可用亮绿强调当前结果。

## 字体与文字

英文、数字用 Consolas，中文回退微软雅黑；短标题与紧凑字段呈现终端和早期窗口的排版感。

## 构图与空间

多个带标题栏的窗口错层叠放，菜单、结果与状态栏对齐到像素网格；指针动作组织视线顺序。

## 材质与图形

以 SVG 窗口、锐利边缘、像素图标和弱扫描线构造桌面质感，代码和数据作为可读内容进入界面。

## 运动与转场

指针点击后窗口或字段步进变化，输入逐字形成并在执行点暂停，再切到结果；窗口动作保持离散而清楚。

## 字幕

字幕置于稳定的浅灰或深色底条，颜色沿用选中状态；字幕字体清晰，不把整段旁白像素化。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。
