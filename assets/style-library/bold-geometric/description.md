# 明亮几何风

ID：bold-geometric

## 风格概述

薄荷绿到浅青渐变底，大尺寸几何对象配橙色强调，圆角形体以弹性节奏组装、变形和接力。适合轻快科普、功能介绍和年轻化品牌内容。

## 配色与层级

背景使用 linear-gradient(125deg,#d7f8e7,#c9eff5)；正文 #172725，次级文字 #52736a，重点 #ff6c42，内容面 #ffffff，分隔线 #abd4c8。强调色用于当前关键对象与结论。

## 字体与文字

标题使用 Microsoft YaHei, sans-serif，字重 800；正文使用 Microsoft YaHei, sans-serif，代码与数字说明使用 Consolas, monospace。主标题、标签与字幕保持明确大小层级。

## 构图与空间

大图形担当主角，文字与形体形成鲜明大小对比；前后层通过遮挡、错位与留白组织。

## 材质与图形

平面几何 SVG 配轻量体积感，较大圆角、柔和投影和明亮色块形成亲近的图形语言。 面板圆角 32px，边框 1px；阴影 0 22px 70px #0002。

## 运动与转场

形体弹性建立、过冲回稳，利用同形对象接力和方向擦除完成切换；落定后保留读图时间。

## 字幕

字幕使用 #172725，底条 #ffffffed，字号基准 36px，圆角 32px；底部位置与安全区随画幅重排，关键词沿用重点色。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。 保留同一对象的空间层级与关注点。
