# 深海

ID：shotcraft-deep-ocean

## 风格概述

深海蓝底与薄荷青强调，浅色文字落在分层深蓝面板上，界面以冷静推近和清楚落点展开。适合数据仪表盘、研究工具和科技产品介绍。

## 配色与层级

背景使用 #0b1620；正文 #e8f1f5，次级文字 #9fb6c3，重点 #7cc8b4，内容面 #142735，分隔线 #304957。强调色用于当前关键对象与结论。

## 字体与文字

标题使用 Microsoft YaHei, Segoe UI, sans-serif，字重 800；正文使用 Microsoft YaHei, Segoe UI, sans-serif，代码与数字说明使用 Consolas, monospace。主标题、标签与字幕保持明确大小层级。

## 构图与空间

产品主体位于主要视觉舞台，内容面板与强调对象组成前后层；总览与特写保持同一页面的阅读关系。

## 材质与图形

深蓝哑光表面配薄荷色边缘高光，柔光与细边维持克制的空间层次。 面板圆角 20px，边框 1px；阴影 0 20px 60px #e8f1f526。

## 运动与转场

聚焦式运镜与分层入场结合，对象建立后停留阅读；共享锚点、顺时针擦除与暖白闪切可承接章节。动作时点由本片实测旁白决定。

## 字幕

字幕使用 #e8f1f5，底条 #142735ed，字号基准 36px，圆角 12px；底部位置与安全区随画幅重排，关键词沿用重点色。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。 保留同一对象的空间层级与关注点。
