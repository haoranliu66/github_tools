# 触感三维小景

ID：tactile-miniature

## 风格概述

奶油色背景与陶土、薄荷色的小型圆润物件，软阴影和俯斜视角建立微缩空间，物件通过挤压回弹、拼装和小幅环绕讲清关系。适合机制科普、流程演示和亲近感产品介绍。

## 配色与层级

奶油底、陶土强调与薄荷辅助色组成柔和小景，物件用相近明暗面形成体积，正文保持深棕色。

## 字体与文字

标题采用清楚圆润的无衬线中文，标签短而大；文字保持平面清晰，与立体物件形成稳定分工。

## 构图与空间

俯斜视角的小舞台上排列对象，接触点、遮挡和相对大小交代关系；一个机制用同一组对象持续演示。

## 材质与图形

用圆润几何、哑光泥塑感和接触阴影体现触感；可以 SVG/CSS 构造浅体积，需要真实相机时使用已安装的 Three.js 与 Remotion Three。

## 运动与转场

物件逐步拼装，落点挤压回弹，连接与结果在同一空间建立；相机小幅环绕后回到可读视角，运动与旁白推进同步。

## 字幕

深棕字幕落在稳定奶油色底条，陶土色强调动作或结果词；物件标签靠近对象，不随相机持续晃动。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。
