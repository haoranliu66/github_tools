# 电影纪实叙事

ID：cinematic-documentary

## 风格概述

深灰与暖白字幕、琥珀时间标记，以全景到特写、资料裁片和缓慢推拉组成有电影感的叙事，关键结论以干净硬切落定。适合人物故事、事件回顾、科技发展和案例讲解。

## 配色与层级

炭灰暗部与暖白信息形成电影式对比，琥珀色用于时间、地点或当前证据；真实素材可沿用统一的冷暖关系。

## 字体与文字

标题使用清楚的衬线字体，说明、日期和数据用无衬线或等宽字；字卡像章节标题，字幕保持稳定。

## 构图与空间

用全景建立语境，再进入对象特写；资料裁片、时间轴和图表与当前叙事并置，旁注靠近被解释的对象。

## 材质与图形

轻颗粒、柔暗角和低调框线呈现纪实观感；素材由当前影片实际准备，图解保持与实拍相同的光色层级。

## 运动与转场

缓推、后拉和焦点切换提供观察感，结论以干净硬切落定；持续时间跟随旁白含义，证据出现后给可读停留。

## 字幕

暖白字幕配低透明度深色底条，时间地点信息与旁白字幕分开；强调色只用于当前关键事实。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。
