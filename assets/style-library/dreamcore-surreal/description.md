# 梦核超现实

ID：dreamcore-surreal

## 风格概述

雾蓝、淡紫与珍珠白的朦胧空间，熟悉物件以悬浮、尺度错位和光晕形成梦境感，镜头缓慢穿行并以形状连续变换。适合概念隐喻、未来想象、情绪叙事和创意开场。

## 配色与层级

雾蓝与淡紫渐变建立朦胧空间，珍珠白层面承载对象，紫色重点和深蓝文字保持阅读焦点。

## 字体与文字

标题以轻盈衬线字体配较松字距，正文保持清楚的无衬线；短句像空间中的注释，与主体保持明确层级。

## 构图与空间

熟悉物件悬浮在开放空间中，通过尺度差、门洞、远近层与柔雾建立梦境视角；主角持续可辨认。

## 材质与图形

柔光晕、半透明雾、轻颗粒与低饱和表面呈现梦感，物件轮廓简洁，形状和空间关系承担隐喻。

## 运动与转场

相机缓慢穿行，物件漂浮或连续变形，从一个熟悉形状接到另一个；关键概念显现后停留再进入下一层。

## 字幕

深蓝字幕置于稳定浅色底条，画面中的短概念注释与旁白字幕分区；字形保持清楚，不一起做模糊。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。
