# 纸墨印刷

ID：shotcraft-ink-press

## 风格概述

暖纸白底、深墨宋体标题与琥珀强调，卡片像纸面印刷层逐步建立，配合聚光、推近和清楚停顿。适合知识整理、论文收藏和编辑式产品宣传。

## 配色与层级

背景使用 radial-gradient(ellipse at 50% 40%,#fdfcfa,#f9f6f1 75%)；正文 #13110f，次级文字 #65635f，重点 #955905，内容面 #fdfcfa，分隔线 #d9cbb4。强调色用于当前关键对象与结论。

## 字体与文字

标题使用 SimSun, Georgia, Microsoft YaHei, serif，字重 600；正文使用 Microsoft YaHei, Segoe UI, sans-serif，代码与数字说明使用 Consolas, monospace。主标题、标签与字幕保持明确大小层级。

## 构图与空间

采用纸面编辑层级，主标题、内容层和重点对象形成明确阅读顺序；页面总览与局部特写保留结构联系。

## 材质与图形

用纸面色阶、细墨线和低对比纸纹建立印刷感，琥珀色用于重要对象与注释。 面板圆角 20px，边框 1px；阴影 0 20px 60px #13110f26。

## 运动与转场

聚焦式运镜与分层入场结合，对象建立后停留阅读；共享锚点、顺时针擦除与暖白闪切可承接章节。动作时点由本片实测旁白决定。

## 字幕

字幕使用 #13110f，底条 #fdfcfaed，字号基准 36px，圆角 12px；底部位置与安全区随画幅重排，关键词沿用重点色。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。 纸面纹理和分隔线跟随新布局重建。
