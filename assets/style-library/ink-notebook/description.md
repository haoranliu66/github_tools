# 手绘讲解

ID：ink-notebook

## 风格概述

横线笔记纸、墨色粗描边、楷体手写感和橙色标注，关系线像现场绘出，对象在图解中移动并落定。适合原理拆解、流程解释和教学。

## 配色与层级

背景使用 repeating-linear-gradient(0deg,#fffaf0,#fffaf0 39px,#e6e0d4 40px)；正文 #242329，次级文字 #77716a，重点 #f08143，内容面 #fffdf8，分隔线 #242329。强调色用于当前关键对象与结论。

## 字体与文字

标题使用 KaiTi, Microsoft YaHei, sans-serif，字重 800；正文使用 KaiTi, Microsoft YaHei, sans-serif，代码与数字说明使用 Consolas, monospace。主标题、标签与字幕保持明确大小层级。

## 构图与空间

像在笔记本上逐步讲解，主体图解占中心，标签、箭头和手写旁注围绕关系就近摆放。

## 材质与图形

用规则纸横线、手绘 SVG、略不规则轮廓和硬偏移阴影形成笔记质感；橙色用于圈点和结论。 面板圆角 6px，边框 3px；阴影 6px 6px 0 #222。

## 运动与转场

先描路径，再沿路径移动例子，最后落到重点标记；画笔擦入、对象匹配与纯色交接延续讲解。

## 字幕

字幕使用 #242329，底条 #fffdf0，字号基准 36px，圆角 4px；底部位置与安全区随画幅重排，关键词沿用重点色。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。 纸面纹理和分隔线跟随新布局重建。
