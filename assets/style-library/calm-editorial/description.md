# 留白杂志讲解

ID：calm-editorial

## 风格概述

暖白与低饱和绿色、衬线标题和细分隔线组成安静杂志版面，以缓慢揭示、局部推近和长短有序的阅读停顿推进。适合深度知识、阅读写作、思考类内容和长信息解释。

## 配色与层级

暖白底、深灰绿正文与低饱和绿色标记，细分隔线和少量淡色信息面帮助组织内容。

## 字体与文字

宋体或 Georgia 衬线标题体现编辑质感，正文采用清楚的无衬线中文；段落行距舒展、标题层级明确。

## 构图与空间

使用有留白的杂志栏式布局，标题、主体图解、引文和旁注共享网格；焦点可从整页移到一处论点。

## 材质与图形

哑光纸面、细线图解、干净留白和低对比影子构成轻质感；内容关系通过对齐和线条呈现。

## 运动与转场

内容缓慢清晰显现、线条逐步建立，重点轻微推近；语义完成后给读图停顿，转场沿用对象或排版锚点。

## 字幕

底部字幕保持清楚且低干扰，关键词用绿色点明；字幕与引文分区，避免把两种阅读任务叠在一起。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。
