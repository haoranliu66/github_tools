# 黑曜紫

ID：shotcraft-obsidian-violet

## 风格概述

近黑紫底、灰紫面板与淡紫高光，明亮标题和分层界面形成柔和神秘感，重点对象渐亮后被镜头锁定。适合 AI 工具、创意软件和夜色科技产品展示。

## 配色与层级

背景使用 #14121b；正文 #f0edf7，次级文字 #b3a9c5，重点 #bca0e8，内容面 #211d2c，分隔线 #41364f。强调色用于当前关键对象与结论。

## 字体与文字

标题使用 Microsoft YaHei, Segoe UI, sans-serif，字重 800；正文使用 Microsoft YaHei, Segoe UI, sans-serif，代码与数字说明使用 Consolas, monospace。主标题、标签与字幕保持明确大小层级。

## 构图与空间

产品主体位于主要视觉舞台，内容面板与强调对象组成前后层；总览与特写保持同一页面的阅读关系。

## 材质与图形

紫黑色面板、柔和紫光和细描边形成轻盈的暗场层次。 面板圆角 20px，边框 1px；阴影 0 20px 60px #f0edf726。

## 运动与转场

聚焦式运镜与分层入场结合，对象建立后停留阅读；共享锚点、顺时针擦除与暖白闪切可承接章节。动作时点由本片实测旁白决定。

## 字幕

字幕使用 #f0edf7，底条 #211d2ced，字号基准 36px，圆角 12px；底部位置与安全区随画幅重排，关键词沿用重点色。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。 保留同一对象的空间层级与关注点。
