# 复古牛皮纸

ID：shotcraft-vintage-kraft

## 风格概述

棕金牛皮纸底、深棕字与棕红强调，纸质卡片以分层入场和轻缓推近展开，整体温暖复古。适合知识收藏、历史回顾和纸面产品展示。

## 配色与层级

背景使用 radial-gradient(ellipse at 50% 40%,#dfc69e,#c8aa7d 75%)；正文 #382a20，次级文字 #6b513b，重点 #8b4937，内容面 #dfc69e，分隔线 #ac895e。强调色用于当前关键对象与结论。

## 字体与文字

标题使用 Microsoft YaHei, Segoe UI, sans-serif，字重 800；正文使用 Microsoft YaHei, Segoe UI, sans-serif，代码与数字说明使用 Consolas, monospace。主标题、标签与字幕保持明确大小层级。

## 构图与空间

产品主体位于主要视觉舞台，内容面板与强调对象组成前后层；总览与特写保持同一页面的阅读关系。

## 材质与图形

牛皮纸色阶、低对比纸纹、较小圆角和棕色细边形成实体纸卡感。 面板圆角 8px，边框 1px；阴影 0 20px 60px #382a2026。

## 运动与转场

聚焦式运镜与分层入场结合，对象建立后停留阅读；共享锚点、顺时针擦除与暖白闪切可承接章节。动作时点由本片实测旁白决定。

## 字幕

字幕使用 #382a20，底条 #dfc69eed，字号基准 36px，圆角 12px；底部位置与安全区随画幅重排，关键词沿用重点色。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。 纸面纹理和分隔线跟随新布局重建。
