# 鼠尾草

ID：shotcraft-solar-pop

## 风格概述

暖浅白底、鼠尾草绿强调与深灰字，白色圆角面板留出舒缓空隙，层次轻轻展开并以重点停留收束。适合效率工具、生活知识和温和的产品说明。

## 配色与层级

背景使用 #f9faf6；正文 #26342b，次级文字 #637067，重点 #527434，内容面 #ffffff，分隔线 #dde4d5。强调色用于当前关键对象与结论。

## 字体与文字

标题使用 Microsoft YaHei, Segoe UI, sans-serif，字重 800；正文使用 Microsoft YaHei, Segoe UI, sans-serif，代码与数字说明使用 Consolas, monospace。主标题、标签与字幕保持明确大小层级。

## 构图与空间

产品主体位于主要视觉舞台，内容面板与强调对象组成前后层；总览与特写保持同一页面的阅读关系。

## 材质与图形

柔和中性底色、自然绿色点缀、低对比细边和轻投影。 面板圆角 20px，边框 1px；阴影 0 20px 60px #26342b26。

## 运动与转场

聚焦式运镜与分层入场结合，对象建立后停留阅读；共享锚点、顺时针擦除与暖白闪切可承接章节。动作时点由本片实测旁白决定。

## 字幕

字幕使用 #26342b，底条 #ffffffed，字号基准 36px，圆角 12px；底部位置与安全区随画幅重排，关键词沿用重点色。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。 保留同一对象的空间层级与关注点。
