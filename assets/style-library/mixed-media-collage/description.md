# 手工混媒拼贴

ID：mixed-media-collage

## 风格概述

暖纸底上叠放撕边剪纸、照片裁片、手写箭头和印刷字块，元素以停格跳动、贴入与翻纸接力展开。适合知识故事、文化解读、创意工具和过程展示。

## 配色与层级

米色纸底、墨棕正文与砖红标记，照片和图形保留各自色彩，重点通过圈点、贴纸和粗字块显现。

## 字体与文字

宋体印刷标题配清楚的无衬线正文，短标签用楷体手写感；字号和排列像剪下贴上的编辑片段。

## 构图与空间

主体裁片与字块非对称叠放，撕边、交叠和窄旁注制造纸面层级；空间关系服务当前故事的阅读顺序。

## 材质与图形

用 SVG 撕边、纸纹、网点、胶带与手绘线构造质感；影片用到的真实图片单独准备并登记。

## 运动与转场

按帧切换纸片姿态形成停格触感，贴入时短促过冲，再以翻纸、画笔揭示或共享剪影衔接；动作与内容解释同步。

## 字幕

暖白字幕纸条或干净底部字幕承载旁白，砖红只强调关键短语，手写旁注就近指向画面对象。

## 画幅适配

横屏按主次组织空间，竖屏将同一信息改为纵向堆叠，保持主角、阅读顺序与字幕安全区；标题按实际文字长度换行，尺寸随画幅调整。
