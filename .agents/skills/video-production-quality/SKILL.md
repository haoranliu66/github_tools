# 视频生成总规范

## 共通原则

研究策划，材料查看，导演统筹和视觉预检由当前聊天主 Agent 执行，不另开研究或导演模型会话。配音按配音 Skill 授权交给子代理；长片镜头按导演 Skill 授权交给子代理。同一份 editorial-plan.json 贯穿制作。只加载当前阶段规范；制作材料通过策划案中的本地链接交付，按需读取，不把源码、媒体编码数据或成套用法直接注入提示词，不预载全库或来源评审。解释性动画和实际观察材料均可用于表达，功能声明以仓库对应 README 为依据；代码和资源以可复现的离线帧渲染执行。不要出现非本机实测，示意建议，仍需确认，下列为虚构的例子，本机没有实际运行项目等边界性描述与研究。不要出现任何对于本项目边界以及本项目在哪个方面不合适等等的描述和研究。

## 研究与策划交付

只研究本片叙事和必要制作决定。交付连续中文旁白、语义单元、风格、完整分镜及实际需要的图片/SVG/媒体。每镜说明表达目的、画面过程与结果、旁白线索和连续关系。
先描述表达需要，用 video:library search 多路检索组件的一段画面与场景说明；组件是首选实现建议。按描述选中后只读该项 usage，确认接口、资源和时长；已读且未变化的说明复用。源码、演示和专项参考只为当前具体问题读取，不批量试看。没有合适组件时可组合或设计专用 JSX。
designContext 只保存共享设计与连续关系；具体实现建议放在镜头中，接口细节按需读取。不要重复风格参数、写查看过程或评审结论。只交付统一计划及使用材料，图片和媒体必须实际就绪；来源归档独立保存，未用候选不交给导演。

## 配音后落实时间

按连续旁白生成配音并测量时长，再落实镜头帧区间。加权语句时间标为估计，不宣称词级对齐。画面修改复用未改变的音频。声音与接口规范按需读取 ../audio-narration-preflight/SKILL.md。

## 导演实现画面

按策划案 contentRoute 加载已选内容 Skill 的导演与当前形式画面要求，不加载其研究章节。未选内容 Skill 时只执行通用导演规范，不默认加载 GitHub 分享要求。
按实测配音时长选择模式：小于120秒为短片，一个整体实现任务生成全片 layout 和全部初版代码；达到120秒为长片，导演确定全片布局、共享代码、设计与各镜头进入/结束状态，子代理实现具体镜头，导演集成并检查全片。初版之后允许根据实际预检进行必要修复，不采用旧的逐视觉段串行导演调用。
导演按策划案本地链接读取已准备材料，不默认重新研究仓库、检索全库或每段重复读取 usage。细节无法满足实际表达时显式补齐材料并更新同一计划。保留自由 JSX/SVG/Canvas，没有固定对象、布局、动作或动效配额。研究分镜不冻结剪切点；通常可为一个语义块设计 2-3 次画面推进作为策划参考。以 planShotIds 保留表达目的，完整覆盖实测音频。
保持故事、事实、旁白、风格与连续关系。长片子代理只读相关镜头、共享设计与所用材料，写自己的文件；同一对象的状态和空间关系通过共享代码与明确衔接保持。用帧驱动动画，整片检查节奏与接缝。按模式读取 ../video-editorial-agent/SKILL.md 对应章节，Remotion 专项参考仅按问题读取。

## 视觉预检与修复

检查实际连续画面与接缝的可读性、变化、关系、连续性与节奏；有意停顿、遮挡或重复依据表达目的判断。blocking/major 问题影响阅读、理解或连续性，必须修复；不妨碍主要信息的 minor 问题允许通过，不强制修复，也不保存具体问题和可选修复建议。
问题提供时间、证据与修复目标，修复后验证实际画面。修复可修改源码或同一计划的 layout；同步状态与受影响实现，保留有效配音、字幕、事实及风格。

## 最终交付

当前程序视觉预检通过后才允许最终渲染。完整音画解码后交付文件与技术信息；人工完整观看和试听决定最终批准，发布单独授权。
