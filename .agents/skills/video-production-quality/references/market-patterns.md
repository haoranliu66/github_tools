# 内容 Skill 的选择与全流程使用

唯一制作流程通过 --content-skill NAME 选择本片内容 Skill，通用选择保存在 preproduction.contentRoute；未选择时只使用通用制作规范，不默认加载任何类型。主 Agent 首次读取所选 Skill 的统一内容要求及所选形式，研究、导演和视觉预检共用，不重复注入正文。

选择 [github-project-sharing](../../content-choose/github-project-sharing/SKILL.md) 时，研究交付观看承诺、故事、贯穿例子、结果镜头及配音前自检，并在 preproduction.sharing 保存专属信息。仅该选择要求 sharing；其他内容不填写该对象，导演与预检不消费它。
该 Skill 的 single-short / single-deep 是内容形式，实测配音小于120秒 / 达到120秒是导演执行模式，两者独立。表达例子和精选片段按需读取，材料继续以本地链接交付。

新增类型提供自己的统一内容 Skill 与可选形式要求；共享流程不强制其他类型填写 GitHub 分享字段。配音与通用视觉证据、严重程度、修复机制保持现行职责。唯一制作流程仍为 docs/video-production-workflow.md。
